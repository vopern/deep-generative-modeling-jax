# Deep Generative Modeling Approaches 101 - Building an Intuition

These are notebooks to explore various methods in generative modeling. 

The idea is to create notebooks with vibe-coded examples and context for a basic intuition 
of more or less recent algorithms, without going to deep into mathematical derivations.

Notebooks
- are not optimized in any way
- do not contain mathematically complete or rigorous derivations
- are not an overview over latest methods
- References are not a complete list of historical contributions, but sources and propositions for further reading 
- Toy examples are constructed for visualization, not usefulness.

Algorithms are implemented using [Jax](https://docs.jax.dev/en/latest/notebooks/thinking_in_jax.html).

## Content

- **Gaussian mixture models** 
- **Variational autoencoders** 
- **Diffusion Models**
- **Score matching Models**
- **Flow Matching**
